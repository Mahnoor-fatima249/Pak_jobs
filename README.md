# 🚀 PakJob Professional Builder

PakJob Professional Builder is an AI-powered career assistant designed for students and professionals to optimize their resumes for ATS (Applicant Tracking System) and generate professional cover letters.

## 🌟 Key Features
- **ATS Performance Analysis:** Get an instant ATS score for your resume based on job descriptions.
- **AI-Powered Optimization:** Rebuild resume layouts and identify skill gaps using advanced AI models.
- **Smart Generation:** Generate tailored, professional cover letters instantly.
- **Skills Gap Analysis:** A clear comparison of "Found" vs "Required" skills in a structured table.
- **User-Friendly Dashboard:** Clean, responsive, and professional UI built with Streamlit.

## 🛠 Tech Stack
- **Python:** Core programming language.
- **Streamlit:** For the web interface.
- **Groq API (Llama 3.1):** High-speed AI inference for resume analysis.
- **Plotly:** For interactive data visualization.
- **PyPDF2:** For PDF parsing.

## 📋 How to Use
1. **Upload or Paste** your resume content.
2. **Paste the Job Description** you are targeting.
3. **Select an Action** (Analyze, Rebuild, or Cover Letter).
4. **Generate & Download** your results instantly!

## 🎓 About
Developed as a specialized tool for students (BSIT) to bridge the gap between academic profile and industrial requirements.
